# 📱 AnimeCatalog

AnimeCatalog is an Android application developed in **Kotlin** that allows users to browse a list of popular anime, rate them, and create personal reviews.

This project was created as part of my Android development learning journey and focuses on building modern Android applications using native components.

---

## ✨ Features

- 🎬 Splash Screen with animated GIF
- 📋 Top 5 anime list
- 🖼️ Anime images
- ⭐ Rate anime (0–10)
- ❤️ Favorite character
- 🎭 Anime genre
- 📺 Number of episodes
- 📝 Personal review
- 📅 Review date
- 📱 Clean and modern user interface
- 🔄 Navigation between multiple Activities

---

## 🚀 Technologies

- Kotlin
- Android Studio
- RecyclerView
- CardView
- Intent Navigation
